V11 GitHub Actions 工作流（iPhone 上传版）

ZIP 小于 500KB。解压后得到：
- build-android.yml
- build-ios.yml

在 GitHub 仓库中创建路径：.github/workflows/
然后分别用网页 Create new file 建立上述两个文件，并把对应 YAML 内容粘贴进去。

注意：仅上传工作流并不足以编译 APK/IPA；工作流引用的 Android/iOS 工程源码仍必须存在于仓库。原 Mobile BuildKit 总 ZIP 本身约 360KB（也低于500KB），但 GitHub Actions 不会自动解压仓库里的 ZIP 作为源码，除非使用专门的 bootstrap workflow。
